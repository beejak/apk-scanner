# Sandbox scan results (public training apps)

These reports were generated by running the local CLI against **freshly downloaded**, intentionally vulnerable / educational Android APKs in a disposable temp sandbox. **APK binaries are never stored in this repository** (see root `.gitignore`).

## How these were produced

1. Create `%TEMP%\apk-scanner-sandbox-<timestamp>\`.
2. Download public training APKs (InsecureBankv2, InsecureShop, DIVA, AndroGoat, InjuredAndroid, OVAA, EasyShop, UnCrackable L1–L3, Sieve, Vuldroid, DVAC, DVL Library, etc.).
3. Run: `python cli.py <sandbox> --types apk --sast -o json` (also html/csv/text).
4. Copy **sanitized** reports here (paths redacted to `<sandbox>`).
5. **Purge** the entire sandbox (APKs + local copies of reports).

Regenerate anytime; do not commit APKs.

## What this shows

Pattern-scan / metadata-heuristic **leads**, not confirmed vulnerabilities. Vague `password` hits remain noisy (low severity). High-confidence formats (e.g. AWS `AKIA…`) and metadata rules (debuggable, allowBackup, exported unprotected) are more actionable.

## Planned local drop-zone UI

A static HTML/JS drag-and-drop page **cannot** run this Python scanner in-browser. A future UI needs a companion local server or Tauri (or similar) wrapper that invokes `cli.py`. That UI is **not** built here — only documented.
